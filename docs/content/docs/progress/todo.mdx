## 实现里已经标明的缺口

- 3D 预演台的程序化布景、排戏和离线逐帧编码仍属后续工作。现行入口和快捷键见 [画布入口](../canvas/canvas-node-manual.mdx)。
- 画布编辑租约尚未覆盖分镜逐行对白等字段。同步合同见 [画布 operations 同步](../backend/canvas-operations-sync.mdx)。
- 全屏剪辑工作台没有挂到路由。`web/src/lib/plugins/builtin/editor/` 会注册插槽，但没有页面挂载 `EditorStoreProvider`。用户剪辑走画布时间线，见功能清单「剪辑成片」。
